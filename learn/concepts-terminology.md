# Concepts & Terminology

### Core Concepts

* **Runtime Orchestration**\
  Coordinating how inference requests are processed across multiple models and services.
* **Unified API Surface**\
  A single API endpoint exposing all Language AI capabilities.
* **Model Routing**\
  Dynamic selection of the most appropriate model based on language, domain, cost, latency, and policy.
* **Tiered Inference**\
  Organizing models into tiers based on capability and cost.
* **Policy Enforcement**\
  Applying governance rules such as access control, quotas, and data locality.
* **Observability Signals**\
  Runtime metrics, logs, and quality indicators emitted during inference.

### Key Entities

* **Tenant** – An organizational unit consuming Language AI services
* **Inference Request** – A request for Language AI processing
* **Routing Policy** – Rules determining model selection
* **Model Tier** – Classification of models by capability and cost

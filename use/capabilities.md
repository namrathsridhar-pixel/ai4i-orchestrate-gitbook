# Capabilities

### Core Capabilities

AI4I-Orchestrate provides the following core capabilities:

* Unified APIs for Language AI capabilities
* Intelligent multi-model routing and selection
* Policy-driven access control and governance
* Cost-aware routing with quotas and SLAs
* Runtime observability and quality monitoring
* Feedback integration with AI4I-Contribute

### Supported Modalities

* Automatic Speech Recognition (ASR)
* Neural Machine Translation (NMT)
* Text-to-Speech (TTS)
* Optical Character Recognition (OCR)
* Large Language Models (LLMs)
* Natural Language Understanding tasks

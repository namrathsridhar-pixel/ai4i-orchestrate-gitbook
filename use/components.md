# Components

### API Gateway

Acts as the unified entry point for all inference requests and enforces authentication and rate limits.

### Intelligent Triage Layer

Classifies requests based on intent, complexity, and language characteristics.

### Routing Policy Engine

Selects the optimal model using cost, latency, language, domain, and policy constraints.

### Tiered Model Backend

Hosts and manages models organized into multiple tiers.

### Response Aggregator

Normalizes responses and emits observability and feedback signals.
